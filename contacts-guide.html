📇 폰 주소록 연동 사용법

고객을 저장하면 정한 이름 형식으로 구글 주소록에 등록되고, 핸드폰에 자동으로 나타납니다.

👤 고객 저장→📇 구글 주소록→📱 핸드폰

1처음 한 번만 — 구글 주소록 연결

  1. 웹 워크스페이스(ympaint-86457.web.app)에 로그인합니다.
  2. 왼쪽 사이드바 🔗 Google → 📇 주소록 연동 을 누릅니다.
  3. 핸드폰과 동기화된 개인 구글 계정을 고르고 허용합니다. (캘린더 계정과 달라도 됩니다)
  4. "✅ 주소록 연동됨" 이 보이면 끝. 이후로는 확장·PC 워크스페이스에서 바로 등록됩니다.
확장에는 구글 비밀번호나 토큰이 저장되지 않습니다. 워크스페이스 서버가 연결된 계정으로 대신 등록합니다.

2핸드폰 설정 — 구글 주소록 동기화 켜기

🤖 안드로이드(갤럭시 등)
  1. 설정 → 계정 및 백업 → 계정 관리
  2. 1번에서 고른 구글 계정 선택
  3. 계정 동기화 → 연락처 켜기
🍎 아이폰
  1. 설정 → 연락처 → 계정
  2. Gmail(구글) 계정 추가 · 선택
  3. 연락처 켜기, 기본 계정을 Gmail 로
등록 후 보통 몇 분 안에 폰에 나타납니다. 안 보이면 폰 연락처 앱에서 아래로 당겨 새로고침하세요.

3번호 저장하기

  • 한 명씩 — 고객 입력 화면의 연락처 칸 옆 📇 번호저장 → ㄴ. 저장 또는 ㅈ. 저장. 고객을 PC 에 저장하고 바로 주소록에 등록합니다.
  • 자동 — 기본으로 켜져 있습니다. 💾 PC에 저장 · 💾📤 PC + 워크스페이스 로 저장하면 전화번호가 있는 고객은 주소록에도 자동 등록됩니다. 이미 주소록에 등록된 고객은 다시 만들지 않습니다.
  • 목록에서 — 고객 카드의 📇 폰 주소록, 여러 명을 한 번에 📇 전체 폰 주소록 등록.
같은 번호의 연락처가 폰(구글)에 이미 있으면 새로 만들지 않고 그대로 둡니다. 가려진 번호(010-****-1234)는 등록하지 않습니다.

4저장 이름 형식 바꾸기

⚙️ 번호저장 설정(고객 목록 위 · 번호저장 메뉴 · PC 워크스페이스 ⚙️ 저장·동기화)에서 형식을 고칩니다. 칸을 눌러 넣고 미리보기를 보며 저장하세요. 처음에는 웹 워크스페이스와 같은 형식이 기본으로 들어 있습니다.

칸뜻예
{프리픽스}ㄴ. 또는 ㅈ. (마지막에 고른 것이 기본)ㄴ.
{이름}고객명 + 님홍길동님
{날짜}등록 날짜 YYMMDD261126
{생년}출생연도 2자리83
{생년월일}생년월일 YYMMDD830520
{연도} {월} {일}등록 연·월·일2026 · 11 · 26
{전화}전화번호010-1234-5678
기본 형식 {프리픽스}{날짜} {이름}({생년}년) → ㄴ.261126 홍길동님(83년)

같은 창의 "PC 에 저장할 때 폰 주소록에도 자동으로 등록" 을 끄면 자동 등록을 하지 않습니다.

5안 될 때

  • "구글 주소록이 연결되어 있지 않습니다" → 1번을 다시 해 주세요(연결이 풀렸을 수 있음).
  • 폰에 안 보임 → 2번 동기화가 켜져 있는지, 1번에서 고른 계정과 폰의 계정이 같은지 확인.
  • 이름이 이상함 → 생년월일이 비어 있으면 (년) 부분은 빠집니다. 이미 등록된 연락처의 이름은 자동으로 바뀌지 않으니, 폰 연락처 앱에서 직접 고쳐 주세요.
