# 토스인슈 CRM 추출기 (Chrome 확장)

토스인슈 CRM 데이터 추출 + 보험료비교 폼 자동입력. **로그인 + 관리자 승인** 권한 게이트 포함.

## 📥 설치 방법

1. [**최신 버전 다운로드**](../../releases/latest/download/toss-crm-extractor.zip) (releases/latest)
2. 받은 `toss-crm-extractor.zip` **압축 해제**
3. Chrome 주소창에 `chrome://extensions` 입력
4. 우측 상단 **개발자 모드** 켜기
5. **압축해제하여 로드** → 압축 푼 폴더 선택

## 🔐 사용 (권한 필요)

1. 확장 아이콘 클릭 → **회원가입** (이메일/비밀번호)
2. 가입하면 자동으로 **승인 대기** 상태가 됩니다
3. **관리자 승인** 후 사용 가능 (관리자가 승인 토글을 켜면 즉시 활성화)

> 승인 전에는 추출·자동입력 기능이 차단됩니다.

## 🖍 토스 보장분석 화면 표시 (3.35.0~)

`crm.tossinsu.com/crm-v2/cover/*` 화면 오른쪽 위 **🖍 표시 도구** 버튼.

- **형광펜**: 칸 또는 줄 이름을 누르면 그 글자 위에만 칠해짐(칸 배경은 그대로). 범위 '이 고객만' / '모든 고객(줄 단위)'.
- **보험 순서 기억**: 토스에서 보험을 끌어 옮기면 고객별로 기억 → 다음에 열면 그 순서로 자동 맞춤.
- **글자 수정**: 화면에 보이는 글자만 바뀜(토스 데이터는 그대로). 점선 칸 = 고친 칸.
- 표시와 수정은 '표' 미리보기에도 적용되므로, 이미지 복사로 페인트프로에 보내는 이미지에도 들어감.
- 안전장치: ↶ 되돌리기(Ctrl+Z), 고객별 '원래대로', '토스 원래 순서로', ⏻ 기능 끄기(팝업 체크박스도 동일).

## 📁 원드라이브·구글드라이브 폴더 동기화 (3.36.0~)

팝업 → 💻 다른 PC에서 쓰기 → **📁 폴더 연결**. 원드라이브/구글드라이브가 동기화하는 폴더를 고르면
보험사 비번·고객정보(건강정보 포함)를 PIN 으로 암호화된 `토스확장_금고.json` 1개로 둡니다.

- 다른 PC 에서 같은 폴더를 연결하면 양방향으로 반영됩니다(처음 연결하는 PC 는 폴더 파일의 PIN 을 따름).
- 같은 항목을 두 PC 에서 고치면 나중에 고친 쪽이 남습니다. 지운 항목도 반영됩니다.
- 바뀔 때마다 `백업` 폴더에 단계별 백업: 최근 20개 · 하루 1개(30일) · 한 달 1개(12개월). **↩ 백업에서 되돌리기**로 복원.
- 크롬을 다시 켠 뒤 폴더 허용을 다시 물으면 **다시 허용**을 한 번 누르세요.

## 🪟 고객관리 팝업 창 (3.37.0~)

👤 고객 탭의 **🪟 팝업 창** 버튼 또는 단축키 **Alt+Shift+C** → 고객 관리만 따로 작은 창으로 뜹니다.
창 위치·크기를 기억하고, 이미 열려 있으면 앞으로 가져옵니다. 창을 넓히면 목록·입력이 2단으로 바뀝니다.
단축키는 `chrome://extensions/shortcuts` 에서 바꿀 수 있습니다.
