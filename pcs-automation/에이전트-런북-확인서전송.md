# 에이전트 런북 — 금소법/상품비교 확인서 전송 (Flutter 구간)

대상: Claude + Chrome 연동(시각 기반)으로 토스인슈 CRM `확인서 전송` 플로우를 반자동 진행.
원칙: **서명·전송(비가역)은 자동으로 누르지 않는다.** 직전까지만 진행하고 사람이 최종 확인·발송.

---

## 0. 사전 준비 (자동화 가능, DOM/데이터)

1. **제안서 파싱** — `ProposalParser.parseProposalText(text)` 로 `보험사·상품명·고객명·보험료·가계약번호` 추출.
2. **고객 보완정보** — 연락처·생년월일은 제안서에 없음 → CRM 고객 레코드 또는 사용자 제공.
3. **상품 매칭** — `PCSProductMatcher.matchProduct(보험사, 상품명)` (CRM 탭 컨텍스트) 로
   `best.procNm` + `best.productCd` + `confidenceGap` 확보.
   - `confidenceGap < 0.05` 면 Top-N 을 사람에게 제시하고 선택 확인받기.

> 매칭으로 "정확히 이 procNm" 을 미리 알아두면, 캔버스 드롭다운에서 모호함 없이 선택할 수 있다.

---

## 1. 진입 (React, 실제 DOM)

- `https://crm.tossinsu.com/crm-v2/center/pcs-documents` 이동.
- 우측 상단 **확인서 전송하기** 클릭 → 새 탭 `/pcs-documents/send` (Flutter) 가 열림.
- 새 탭 `tabId` 로 전환해 이후 진행.

> 직접 `flutter-app#/new-document` URL 진입은 세션 컨텍스트가 없어 `다음` 이 동작하지 않음. 반드시 위 버튼으로 진입.

---

## 2. Flutter 구간 (시각 기반 — 좌표는 창 크기에 따라 다르므로 매 단계 스크린샷으로 확인)

아래 좌표는 1568px 너비 기준 참고값. **항상 screenshot 으로 현재 위치를 확인하고 클릭**한다.

### 2-1. 확인서 종류 선택
- 화면: "확인서 종류를 선택하세요 (중복 선택 가능)" — `상품비교 확인서`, `금소법 고지 확인서` 기본 둘 다 체크됨.
- 동작: 그대로 **다음** (하단 버튼).

### 2-2. 기본정보 입력  (스텝퍼: 기본정보 → 상품비교 → 금소법 → 서명&완료)
- 4칸: 고객명(필수) / 연락처(필수) / 증권번호(선택) / 생일(필수).
- 각 칸을 클릭 후 타이핑(자동 포맷됨: `010-4882-5086`, `1983-11-14`).
- 빈 영역 클릭으로 포커스 해제 후 **다음**.
- 참고 좌표: 고객명 y≈226, 연락처 y≈280, 생일 y≈390, 다음 y≈467.

### 2-3. 상품비교 (핵심)
1. 카테고리 선택: **장기 / 일반 / 자동차** 중 해당(건강보험=장기). 클릭 → 체크.
2. **보험사 검색** 칸 클릭 → 보험사명 입력(예: `메리츠`) → 드롭다운에서 정확한 항목(예: `메리츠화재`) 클릭.
3. **상품명 검색** 칸 클릭 → 매칭된 `best.procNm` 의 **구별되는 부분**을 검색어로 입력
   (예: `통합간편건강` + 필요시 버전 `3.10.5`). 후보가 좁혀지면 스크린샷으로 옵션 텍스트를 읽고,
   `best.procNm` 과 **글자 단위로 일치**하는 항목을 클릭.
   - 주의: 후보들이 `3.10.5 vs 3.0.5`, `세만기형 vs 연만기형`, `통합간편심사형 vs 355수술고지` 처럼
     미세하게 다름. 반드시 매칭 결과 문자열과 대조해 선택.
4. **다음**.

### 2-4. 금소법
- 고지 확인 단계 진행(화면 지시에 따라). 스크린샷으로 확인하며 진행.

### 2-5. 서명 & 완료  ⛔ 정지
- 여기서 **멈춘다.** "고객에게 URL 발송 / 서명 요청" 은 비가역.
- 사람에게: 입력값 요약(고객·상품·보험료) + 매칭 상품(procNm/productCd) 을 보여주고
  **최종 전송 여부를 확인**받는다. 승인 시에만 사람이 직접 전송.

---

## 3. 체크리스트

- [ ] 제안서 파싱 결과 확인(보험사·상품명·고객명)
- [ ] 매칭 confidenceGap ≥ 0.05 (아니면 사람 확인)
- [ ] 진입은 `확인서 전송하기` 버튼으로(세션 컨텍스트)
- [ ] 기본정보 4칸 정확 입력
- [ ] 상품명 = 매칭 procNm 과 글자 일치하는 항목 선택
- [ ] 서명·전송 직전 정지 → 사람 확인
