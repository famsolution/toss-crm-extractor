🆕 확장 프로그램 업데이트 방법

처음 한 번 자동 업데이트를 켜 두면, 새 버전이 나올 때 확장을 여는 순간 알아서 설치되고 다시 켜집니다.

① 자동 업데이트 켜기 (한 번)→② 새 버전 나오면 자동 설치→✅ 최신 버전

1처음 한 번 — 자동 업데이트 켜기

  1. 확장 머리말의 v버전 표시를 누르고 ⬆ 자동 업데이트 켜기 를 누릅니다. (새 버전 안내 띠의 ⬆ 업데이트 를 눌러도 같습니다)
  2. 새 창이 열리면 [확인] → 확장 프로그램을 압축 풀어 둔 폴더(안에 manifest.json · update.bat 이 있는 폴더)를 고릅니다.
    모르겠으면 chrome://extensions → 상담 도우미 → 세부정보 → 소스 에 나오는 폴더입니다.
  3. 크롬이 묻는 창에서 「파일 수정 허용」을 누릅니다. 「방문할 때마다 허용」이 보이면 그걸 고르세요 — 다시 묻지 않습니다.
저장한 비번·고객정보·설정은 크롬 안에 보관되어 있어서 업데이트해도 그대로 남습니다.

2그다음부터 — 자동

  • 새 버전이 나오면 확장 아이콘에 NEW 와 윈도우 알림이 뜹니다. (확인은 3시간마다 자동)
  • 확장을 열면 "새 버전 자동 설치 중…" → 몇 초 뒤 스스로 다시 켜집니다. 확장을 한 번 더 열면 새 버전입니다.
  • 크롬을 다시 켠 뒤 폴더 허락이 풀려 있으면 띠에 ⬆ 업데이트 가 보입니다 — 한 번 누르고 허용만 하면 됩니다.
  • 열려 있던 CRM 탭은 업데이트 뒤 한 번 새로고침(F5) 해 주세요.

3알아 두기

  • 머리말 v버전 메뉴: 새 버전 확인 · 폴더 다시 고르기 · 자동 설치 끄기/켜기.
  • 자동 설치가 안 되면 예전처럼 확장 폴더의 update.bat 을 더블클릭한 뒤 확장을 다시 열어도 됩니다.
  • 받는 것은 공개된 최신 설치 파일(zip) 뿐이며, 고객정보는 어디에도 보내지 않습니다. 고른 폴더가 지금 쓰는 확장 폴더가 맞을 때만 덮어씁니다.
